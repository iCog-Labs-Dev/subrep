Generated by `experiments/caution_recovery/measure.py`. Not hand-edited.

## Setup

- Seeds 1–40, 840 episodes flown once (crash 457, landing 279, timeout 104). The noop baseline: crash 40.
- Candidates: borderline set (6), task set (8), tradeoff set (6), from `experiments/epsilon_scale/collect.py`.
- MetaMo commit `4171b1d`; governor from `make_lunar_lander_governor`; flown on Linux.
- Risk is the bridge's default: the worst objective change against noop. No outcome carries a measured risk.
- Two Safety conventions, both computed from the same episodes:
  - **kept: Safety = landing reward + shaping (the convention in use)**: payoff scale 50.0, motive scale 229.0
  - **once: Safety = shaping only (the alternative convention)**: payoff scale 50.0, motive scale 204.0
- Scales use the demo's formula (`appraisal_scales`) on the task set on seed 1. The demo applies it to whichever candidate set it runs (66.7 / 266.7 with `--candidates ppo`), so eps and Securing here are not directly comparable with the demo's.
- Improvements are against the noop baseline flown from the same seed. Flown outcomes are appraised as admitted; a rejected one adds 0.25 to risk.
- Conduciveness in sections 1 and 2 uses a fresh governor's weights (Safety 0.632).
- eps is clipped to [0, 0.5]; 0.0000 means it is at the lower bound.
